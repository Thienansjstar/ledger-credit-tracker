    Sync across devices

    Without this, check-offs live only on this device. Add a Supabase project and a sync code to share them across your phone and laptop.

    Use the same code on every device. Anyone with the code can read your check-offs, so keep it private — no card numbers are ever stored.

    Reminders

    Download a calendar file and import it once. Your phone handles the reminders from then on — no notification permissions, and it keeps working even if you delete this app.
